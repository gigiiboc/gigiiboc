        고객센터 전화번호와 운영시간을 알려주세요

        • -전화번호 : 080-022-0182/ FAX : (02) 3668 - 8900
        • -운영시간 : 월~일 09:00~20:00 (설날, 추석 연휴 제외)

        1:1 E-Mail 내역은 어디에서 확인하나요?

        홈페이지 우측 상단에서 [마이페이지] 메뉴를 클릭하면 이동한 페이지에서 확인하실 수 있습니다. 상단 메뉴 중 1:1 E-mail 내역을 클릭하시면 문의내역 및 답변내역을 조회하실 수 있습니다. 또한 문의내용 작성 시 입력해 주신 이메일로도 답변내용을 전송해 드립니다.
        마이페이지 바로가기

        PC문제/오류

        1. 로그인/로그아웃이 안됩니다.
        • 1)아이디를 정확히 입력 하셨는지 다시 확인해 주세요.
          • -아이디는 영문(대/소문자 구분)+숫자 조합 8~12자리 이내로 입력해 주셔야 합니다. (2017년 5월 25일 이전 가입자는 4~15자리 영문+숫자 조합)
          • -[CAPS LOCK]이 켜져 있지 않나요? NIKE.COM 에서는 아이디에서 대/소문자를 구분하고 있습니다.
          • -아이디가 기억나지 않을 경우 로그인 팝업 내에 있는'아이디 찾기' 기능을 활용하여 아이디를 찾을 수 있습니다.
        • 2)패스워드를 정확히 입력 하셨는지 다시 확인해 주세요.
          • -패스워드는 8~12자의 영문(대/문자 구분)+숫자+특수문자 조합으로 이루어져 있습니다. (2017년 5월 25일 이전 가입자는 6~12자의 영문(대/문자 구분)+숫자 조합)
          • -[CAPS LOCK]이 켜져 있지 않나요? NIKE.COM 에서는 패스워드에서 대/소문자를 구분하고 있습니다.
          • -패스워드가 기억나지 않을 경우 로그인 팝업 내에 있는'패스워드 찾기' 기능을 활용하여 패스워드를 찾을 수 있습니다.
        • 3)보안프로그램이 로그인 팝업을 차단하고 있을 수 있습니다. (로그인 팝업 자체가 열리지 않을 경우)
          • -고객님의PC를 보호하기 위해 특정 프로그램 설치가 되어 있지 않은지 확인해 주십시오.
          • -구글툴바나 야후툴바 또는 애드웨어를 제거하는 특정한 프로그램 등에 팝업을 차단하는 기능이 들어 있습니다.
          • -바이러스/스파이웨어(악성코드)의 영향으로 인터넷 익스플로러에 오류가 있을 수 있습니다. 열었던 창을 모두 닫고, 바이러스/스파이웨어(악성코드) 검사를 하시는 게 좋습니다.
        • 4)브라우저에 남아있는 캐시 및 쿠키를 삭제해 보기
          • -구글 크롬 브라우저를 사용하시는 고객(PC 모바일 동일합니다.)
            • 1)Chrome을 엽니다.
            • 2)브라우저 툴바에서 더보기(더보기 이미지 삽입)를 클릭합니다.
            • 3)마우스로 도구 더보기를 가리킨 후 인터넷 사용 기록 지우기를 클릭합니다.
            • 4)'인터넷 사용 기록 지우기' 상자에서 쿠키 및 기타 사이트, 플러그인 데이터와 캐시 이미지 및 파일 체크박스를 클릭합니다.
            • 5)삭제할 데이터의 양을 선택하려면 상단의 메뉴를 사용합니다. 모두 삭제하려면 전체를 선택합니다.
            • 6)인터넷 사용 기록 지우기를 클릭합니다.
          • -인터넷 익스플러를 사용하시는 고객
            • 1)인터넷 익스플로러를 실행합니다.
            • 2)도구-인터넷옵션을 선택합니다.
            • 3)일반탭-임시인터넷 파일 부분에-쿠키삭제, 파일삭제('오프라인 항목을 모두삭제' 체크하시고) 합니다.
            • 4)설정-개체보기-모든 개체를 삭제 합니다.(삭제된 개체는 사이트 접속시 자동으로 재설치 됩니다.
            • 5)보안탭으로 이동하셔서 인터넷, 로컬인트라넷, 신뢰사이트, 제한사이트 각각 선택하셔서 기본수준 버튼을 누릅니다.
            • 6)개인정보탭으로 이동하셔서 보통으로 되어 있는지 확인하시고 그렇치 않다면 기본값 복원 버튼을 누릅니다.
            • 7)내용탭으로 이동하셔서SSL상태지우기를 누릅니다. 그리고 자동완성탭을 클릭하셔서 폼지우기, 암호지우기를 합니다.
            • 8)고급탭으로 이동하셔서-맨밑에 기본값 복원을 클릭 후 중앙에 있는 상하 스크롤바를 맨 밑으로 내리신 뒤
            • 9)'URL 항상 UTF-8 로 보냄' 체크 해제
            • 10)타사브라우저 확장명 사용 체크 해제합니다.
            • 11)적용, 확인 버튼을 누르신후 인터넷 익스플로러를 종료합니다.
          • -Apple Safari를 사용하시는 고객
            • 1)방문 기록과 쿠키를 삭제하려면 설정> Safari > 방문 기록 및 웹 사이트 데이터 지우기를 탭합니다.
            • 2)Safari에서 방문 기록, 쿠키 및 브라우징 데이터를 지우더라도 자동 완성 정보는 변경되지 않습니다.
            • 3)저장된 기타 정보를 제거하려면 설정> Safari > 고급> 웹 사이트 데이터> 모든 웹 사이트 데이터 제거를 탭합니다.
        • 5)웹브라우져 확인사항 체크

          아이디, 패스워드가 맞는데도 로그인이 되지 않으실 경우에는 회원님의PC에서 웹브라우져의 확인사항을 체크해 주십시오.
          회원님의 웹브라우져 상단의 도구> 인터넷 옵션> 고급 에서 ‘SSL 2.0사용’과 ‘SSL3.0사용’이 체크되었는지 확인해 주세요.
          위의 방법대로 했는데도 문제를 해결할 수 없을 때는 고객센터080-022-0182로 연락 주시면 도와드리겠습니다.

        • 6)로그인/로그아웃이 안됩니다(버전문제)
          • 1)인터넷 옵션 → 도구 → 개인정보 → 기본값 클릭→ 개인정보 설정을 [보통]으로 세팅
          • 2)인터넷 버전 확인해 주시고, 아래와 같이 설정 바랍니다.

            (버전확인은 인터넷화면 도움말 → (하단)인터넷익스플로러 정보를 통하여 가능합니다.)
            * 인터넷 버전 5.5일경우
            도구 → 인터넷옵션 → 보안 → 사용자정의수준 → 쿠키(두부분 모두 사용으로 클릭)
            * 인터넷 버전 6.0일경우
            도구 → 인터넷옵션 → 개인정보 → 고급옵션

        • 7)결제하려는데 안심클릭 오류가 납니다. (ActiveX 재설정 방법)

          고객님의 pc에 설치된 안심클릭 처리관련 프로그램이 제대로 동작하지 않는 경우가 있습니다.
          같은 페이지의 개체보기 버튼을 눌러 'AnsimPluigin Class XacsPop Control' 위 두개의 액티브엑스 파일이 있다면 삭제합니다.
          다시 결제페이지로 들어가셔서 새로운 액티브 엑스(Active X)를 설치하신 후 결제를 진행해 보세요.

          위 파일들이 아예 보이지 않는다면, 고객님 PC의 브라우져에서 안심클릭 Active X 설치를 막는 원인을 찾아 수정해 주셔야 합니다.
          결제페이지에서 Active X 다운시에 주소창아래 팝업이 차단이 되었다는 메세지가 보일 경우 '팝업이 차단되었습니다. 팝업 또는 추가 옵션을 보려면 여기를 클릭하십시오.' 라는 경고창을 클릭합니다. 현 사이트의 팝업을 항상 허용을 클릭합니다. '현재 사이트의 팝업 창을 허용하시겠습니까?' 에서 '예'를 클릭합니다. 인터넷창 맨위의 '도구-팝업차단-팝업차단 설정'을 클릭하여 허용할 웹사이트 주소에 '*.nikestore.co.kr' 을 입력하고 추가버튼을 누릅니다. 브라우져를 닫은 후 새로 열어 나이키닷컴 결제페이지로 들어갑니다.

        • 8)매번 보안 표시줄이 나타나서 번거롭습니다. 좋은 방법이 없을까요?

          해당 사이트를 신뢰할 수 있는 사이트 목록에 등록하십시오. 메뉴 → 인터넷 옵션 → 보안 → 사이트에서 웹 사이트를 추가하면 됩니다.
          신뢰된 사이트의 보안 설정을 별도로 지정 가능하며, 적절한 보안 수준으로 낮춰 변경하면 됩니다. 일반적인 인터넷 사이트들은 신뢰할 수 있는 사이트로 추가하는 것을 권장하지 않습니다.

        • 9)사이트를 신뢰할 수 있는 사이트로 등록하였는데, 알 수 없는 영역으로 표시가 됩니다.

          신뢰할 수 있는 사이트의 페이지 안에 외부의 다른 사이트 컨텐츠가 존재하기 때문입니다. 신뢰할 수 있는 사이트의 컨텐츠와 외부의 컨텐츠는 별도의 보안설정이 적용됩니다.

        현금영수증 및 전자영수증

        3. 현금영수증제도란?

        2005년 1월1일 부터 시행하게된 현금 영수증 제도는, 현금으로 거래할 경우 현금영수증을 발급하는 새로운 거래증빙제도 입니다.

        [ 현금영수증 종류 ]

        • -소득공제용 : 일반 개인의 소득공제용
        • -지출증빙용 : 사업자의 지출증빙용

        국세청에 통보된 현금결제 내역은 신용카드(직불카드 포함) 사용금액과 합산돼 연말정산 때 소득공제를 받으실 수 있으며, 현금영수증 홈페이지에 휴대폰번호, 신용카드, 적립식카드 등 본인 인식 매체와 함께 사용자등록(회원가입)을 하시면 현금영수증 홈페이지에서 현금영수증 사용내역을 확인하실 수 있습니다.
        현금영수증 신청시, 사용하시는 모든 인식 매체는 현금영수증 홈페이지에 회원가입 및 사용등록이 되어 있어야 혜택을 받으실 수 있습니다.

        자세한 문의는 국세청 홈페이지(http://www.nts.go.kr/)나 현금영수증 홈페이지(http://현금영수증.kr/)를 참조하시기 바랍니다.
        >> 현금영수증 상담센터 : ☎ 1544-2020

        4. 현금영수증은 어떻게 신청하나요?

        현금영수증은 현금영수증 발급대상 상품을 현금성 결제수단으로 주문하신 건에 대하여 발급이 가능합니다.

        [ 신청방법 ]

        • -주문시 신청 : '주문서 작성 페이지'에서 위 신청요건을 만족하는 경우 현금영수증 신청부분이 생성됩니다.
        • -주문후 신청 : 나이키닷컴 고객센터로 신청하시면 됩니다.

        저희 나이키 스토어는 주문자의 주민등록번호(법인회원의 경우, 사업자등록번호)를 기준으로 현금영수증을 발급해드립니다. 주문자가 아닌 타인의 명의로 발급을 희망하실 경우, 타인의 인식매체(주민번호, 휴대폰번호, 신용카드 등)를 확인하시어 나이키닷컴 고객센터로 신청하시기 바랍니다.

        5.현금영수증 신청이 가능한 결제수단은?

        현금성 결제수단인 실시간 계좌이체로 결제하신 주문에 한해 현금영수증을 신청하실 수 있습니다.

        6.현금영수증 발급내역을 보려면 어떻게 해야 하나요?

        신청하신 현금영수증을 출력하려 하시는 경우, 나이키닷컴에 로그인 후 [마이페이지] 주문상세내역에서 [영수증 인쇄하기]->전자영수증의 [전표]를 클릭하시면 현금영수증을 출력 하실 수 있으며 발행시점은 [상품 발송완료] 이후 입니다.
        현금영수증 사용내역은 전산으로 수록되어 현금영수증 홈페이지(http://현금영수증.kr)에서 3개월간의 사용내역(일자,상호,금액 등) 및 1년간의 월별 사용내역을 확인할 수 있으므로 내역확인이 되면 보관하실 필요는 없습니다.

        현금영수증 홈페이지(http://현금영수증.kr)에서 결제일 또는 등록일 다음날 9시부터 조회됩니다.

        회원정보 변경 및 탈퇴

        1. 패스워드를 변경하고 싶습니다.

        나이키닷컴 로그인 후 [마이페이지] > [회원정보관리]을 클릭 하여 이동한 페이지에서 [패스워드 재발급]을 클릭 하시면 됩니다.
        패스워드는 회원님의 안전한 정보보호를 위해 비밀번호를 주기적으로 변경할 것을 권해드립니다.
        쉬운 비밀번호나 자주 쓰는 사이트의 비밀번호와 같으면 도용될 수 있으니 주의하세요.

        2. 회원정보는 어떻게 변경하나요?

        홈페이지에 로그인 하신 후 [마이페이지] > [회원정보관리]메뉴를 클릭 하시면 이동한 페이지에서 변경하실 수 있습니다.
        휴대폰과 이메일 주소, 배송지 주소는 주문 시 배송정보 등 서비스와 관련된 정보를 제공 받으실 수 있으니 변경 되었을 경우 수정해 주시길 권장 드립니다.

        [ 주의사항 ]

        • 1)회원 이름/아이디는 변경이 불가합니다.
        • 2)패스워드, 성별, 생년월일, 연락처, 휴대폰, E-Mail주소 및 배송지 주소는 변경이 가능합니다.
        3. 실명 인증 확인 오류 시 어떻게 하나요?

        고객님의 실명확인에 사용되는 정보는 은행연합회로 집중되는 금융권 정보와 서울신용평가 SIREN24의 기업회원을 통해 집중되는 정보가 사용됩니다. 이러한 신용정보는 해당 기관(업체)들이 고객과의 상거래(신용카드 발급 등) 발생시 취합 되는 정보들인데, 정보를 입력하는 과정에서 주민번호 및 성명정보를 잘못 기입하는 경우가 있습니다.

        (예) 라가명 → 나가명, 나불량 → 나불양, 홍길동 → 홍길도

        본인이 실명임에도 불구하고 일치하지 않는다고 나타나는 경우는 대부분 이런 이유이므로 실명확인고객센터를 통해서 개인 신용정보DB를 수정하실 수 있습니다.
